unrelease:
The game's spoken title is now Sixth Sense Reborn: The Afterlife, on the main menu and in the welcome message, instead of Sixth Sense Reborn: The Zombies, which kept the original game's subtitle.
The Buy button in the shop now clicks when you press it, like every other button there, before the screen reader says whether the weapon was bought.

26.10.07-1:
The license beside the game, license.txt, now names everyone who wrote part of it: tsatria03, lbk2907, tunmi13productions and mzanm. It is the same MIT license as before.
The credits in this readme now say who did what, the big things rather than every fix: tsatria03 owns and publishes the game and carries on checking it against the original, tunmi13productions wrote controller support, the screen reader speaking everything, the fighting, pausing, the Settings screen and the Linux version, and mzanm, who is credited for the first time, made the macOS version. lbk2907 started the port and Bitbee made the game.
A new setting, controller support, turns the game's use of a controller off altogether, for a controller you have plugged in but do not want to play with. Turning it off plays the controller lost sound if you had one plugged in, since the game has just let go of it, and from then on the game does not notice a controller at all: the keyboard plays the game, nothing vibrates, and no controller sound plays. Turning it back on looks for the controllers you have plugged in, as starting the game does, and plays the found sound and the buzz for each one it finds. It starts on, and the game remembers it. While it is off, the vibration, shake and controller rows say they are not supported and tell you why when you press them.
Unplugging a controller the game is not playing with no longer pauses your game. Only losing the controller in your hands pauses it, so nothing happens to you while you plug it back in. With more than one controller plugged in, taking away any of the others now leaves your game alone, your aim and a burst of fire included, and a controller the computer has listed twice no longer pauses the game when it drops one of its listings.
Your key bindings and settings now always have a backup beside them, keys.json.bak and settings.json.bak, made as soon as the game starts if there is not one already. If keys.json is ever damaged, the game now carries on with the keys from its backup instead of the default keys.
The save is now a set of short files in folders, each holding one thing, instead of one long save.json. Your settings and keys are in config, the shop's rules and what you have are in store, each weapon has its own file in weapons, and your progress is in saves. The files use plain names, such as damage in weapons/shotgun.json and the weapons you own listed by name in store/inventory.json. A save from an older version is moved into the folders by itself the first time you start the game, and the old files are kept with .old on the end of their names.
A weapon level set in save.json above the weapon's maximum level now counts only up to that maximum, in play and on the weapon's page. It used to count in full while the page read something like level 15 of 10. The number you wrote is kept, so raising the maximum lets it count again.
On a Mac, Sixth Sense Reborn now has an app identity of its own instead of the one it shared with the original Sixth Sense, so the system no longer mistakes one for the other. Your save is not affected.
The download is much smaller, because it now carries only the sounds the game plays. The old speech recordings, which the screen reader replaced, and other sounds the game never used are no longer included, which takes about 70 megabytes off.
Every setting is now in settings.json from the first start, not only the volumes. Vibration, the spoken headshot, the headshot beep, shake to break free, the controller and skipping the opening screens used to appear there only once you changed them on the Settings screen. They start at the same values as before, so nothing sounds different, and a setting you have already changed is kept.
The pause and result panel in the game window no longer says that restarting costs a coin. Games have been free since the coins were removed, but the window's label had not caught up.
Old saves no longer keep the coin settings, which the game stopped using when games became free. They are taken out of the save the next time the game starts, and the rest of your progress stays as it was.
Shaking a controller to get free of the animal zombie now takes one shake, or two at most, instead of up to five. Shaking is a real movement rather than a button, so it should not have to be aggressive. The A button still takes up to five presses as before, and presses and shakes count together.
The tutorial's first message now says that you can hear any message again at any time, not just that one. It told you which key repeats the message, but never that the same key keeps working for every message after it.
The tutorial's reloading lesson now mentions the D-pad. With a controller it said to pull the left stick down or press X, and left out that pressing the D-pad down reloads as well, which it always did. Every other lesson already named the D-pad.
A new setting, skip the opening screens, takes you straight to the main menu when you start the game instead of the publisher's logo and the earphone warning. It starts off, so you see them as before, and the game remembers it.
The wait after "Now loading" is shorter, 1.3 seconds instead of 2.8, so a level starts sooner. Nothing was ever loading during that wait: the game is ready in about twenty thousandths of a second, and the rest was time set aside for the old recorded "Now Loading", which the game no longer plays.
The main menu's settings are now behind one Settings row, so the menu is the title, Start Game, Tutorial, Store and Settings. Vibration, spoken headshot and headshot beep moved onto the settings screen, where Escape goes back to the menu, and the game remembers them all as before.
Two new settings. Shake to break free turns off the shaking of a controller that can sense it, such as a PlayStation DualSense, if a stray flick keeps shaking the zombie off; it starts on, and the A button works whether it is on or not. Controller says which controller the game is using and lets you move to the next one you have plugged in, which matters when more than one is connected: the game then plays with that one only and ignores the others. It remembers the controller by name, so unplugging things and plugging them back in does not lose your choice, and a controller the computer has listed twice no longer looks like two.
A setting the game cannot use now says so, such as "Vibration, not supported", and tells you why when you press it instead of changing anything. That happens with no controller plugged in, or with a controller that cannot do that thing, such as one with no motion sensor for the shake. Your setting is kept underneath, so a controller that can do it later finds the choice you made.
You can now put your weapons in the order you want. The inventory's last row, Reorder weapons, opens the weapons you have equipped: Up and Down walk the list, and Shift with Up or Down moves the weapon you are on, saying what it did, such as "MG80 moved above Colt". On a controller the left stick walks the list and the two bumpers move a weapon up and down. That order is the order Tab takes you through in a game, and the weapon at the top is the one you start with. A weapon you unequip keeps its place and comes back to it when you equip it again, and the order is WEAPON_ORDER in save.json.
Your gold, GOLD, is always in save.json now, at 0 in a new save, so you can see and change it. Before, it only appeared once a game had paid out or you had bought something.
Weapons can be upgraded. Each weapon's page has a level, such as "Level, 3 of 10", and an upgrade button, "Upgrade stats to level 4 for 173 gold", which raises the weapon's damage, ammo capacity and range together. Each level adds 15 per cent of the weapon's own damage, magazine and range, so a weapon at level 10 is two and a half times the weapon it was: a colt of 7 rounds, 30 damage and 10 metres holds 18, does 75 and reaches 25 metres. The range moves a whole metre at a time, so the knife and the sword, which are only 2 and 3 metres to begin with, keep the same range for a level or two at a time. The price starts at 100 gold and grows by a fifth a level, so reaching level 10 costs 2,596 gold in all. In the shop the upgrade button takes Buy's place once a weapon is yours, and the grenade keeps Buy beside it. Every weapon you own can be upgraded from its inventory page, the knife and the colt only there. Each weapon stops at level 10, and the levels, the caps, the prices and how much a level adds can all be changed in save.json.
Your grenade count, GRENADECOUNT, is always in save.json now, at 0 until you buy a grenade, so you can see and change it. Before, it only appeared once you had bought one.
Starting a game or the tutorial says "Now loading" through your screen reader again, as the original's recording did.
A game now pays 15 gold for each zombie you kill and 5 for each headshot, instead of the original's 12 and 2, so weapons are a bit easier to get. Both are in save.json as GOLD_PER_KILL and GOLD_PER_HEADSHOT, and changing them changes what every later game pays. A number the game cannot use is put back. The weapon test range still pays its own way, a share of its score.
Each weapon's numbers in save.json are now the ones the game really plays with, and changing them changes the game: AMMO_CAPACITY is the magazine, RANGE how far it reaches in centimetres, DAMAGE what a hit takes off, and PRICE what the shop charges, such as SHOTGUN_DAMAGE for the shotgun's damage. They have underscores between the words, to be easier to read, and an older save's names without them, such as SHOTGUNDAMAGE, are renamed by themselves. Every weapon has them from the start, bought or not, and a number the game cannot use is put back. The shop and the inventory read them out, so they always agree, with the range in metres, such as "10 metres". The knife and the sword say "Ammo capacity, none", and the knife and the colt "Price, free". The grenade now hits only the zombies within its range, which at 16 metres is every zombie, as before. An older save's numbers, which were the original shop's and did not match the game, are replaced once.
After buying a weapon, the screen reader says "Purchase has completed", the same words as the window, instead of "Purchase has been completed".
In the weapon test range, two zombies that reach you at once on your last heart no longer leave you below zero hearts without dying. You die as soon as you are at zero or below.
A volume or the gameplay gain in settings.json written with an unusual digit, such as a superscript two, no longer stops the game from starting. It counts as 100, or 0 for the gain, like any other bad value, and the file is left as you wrote it.
A zombie that has grabbed you no longer takes a heart while the game is paused, and its grab no longer carries on after a restart. The pause holds the grab and continuing gives back the time you had left to shake it off.
Pausing just as you die no longer lets the death go ahead under the pause or end the game you restart into. The pause holds the death, and continuing lets it go on.
In your first game after the tutorial, Escape now pauses the game instead of going back to the menu, and restarting from the result panel starts the game again instead of the tutorial's first lesson, where you could not walk and P did nothing.
Two new rows in the main menu: "Spoken headshot" turns the "Headshot!" call on or off, and "Headshot beep" turns on a beep that plays where the zombie is on every headshot, even when it survives the shot. The call starts on and the beep off, and the game remembers both in settings.json as HEADSHOTSPEECH and HEADSHOTBEEP.
The voice over row is gone from the main menu, and with it the recorded voice: the game is always read by your screen reader. A save that had voice over on or off is not affected, and its old setting is dropped from settings.json. The opening screen's welcome now says the game is read by your screen reader and to use stereo headphones.
The tutorial is now spoken by the screen reader instead of the recordings: each lesson says what is coming and then the keys, or the controller's buttons, to use. The lessons with a zombie then wait: press Enter, or A on a controller, and it comes in. Any other key says the lesson again, or Y on a controller, and does nothing else, so you cannot shoot or reload past a lesson. Escape still leaves the tutorial. The ending says "Tutorial success", counts "3, 2, 1" and says "Zombies are coming". The words are first drafts.
Changing weapon now says the weapon's name.
During play, the screen reader now says "Headshot!" and the pause and result panel instead of the recordings. The "Now loading" recording is gone.
The game no longer stops with an error as it starts when a PlayStation DualSense controller is attached on Windows. Unplugging such a controller is now noticed too: its sound plays and the game pauses.
A game controller that can sense motion, a DualSense for one, can now be shaken to shake the animal zombie off, as well as pressing A or Cross. A controller without a motion sensor, an Xbox one, only has the button, and the tutorial only mentions shaking the controller to one that can.
With a game controller attached, the tutorial now says how to do each lesson on it after its words: push the left stick left to shoot toward 9 o'clock, diagonally up and left for 10:30, or press the D-pad's left and up together, and so on through reloading, changing weapon, shaking off the zombie and ending the tutorial. A PlayStation controller hears Square, Cross, Circle, Options and R1 for its buttons.
The zombies in the 10:30 and 1:30 lanes, and the shots and swings aimed there, are now heard closer to 12 o'clock, 20 degrees off centre instead of 33, so it is easier to tell which lane a zombie is in. Only where the sound is placed changes; the zombies, the lanes and the aiming stay as they were.
The girl who heals you now says only "thank you". The kiss after it is cut off.
The man who comes in the girl's place now vibrates a game controller when he hits you: a short wind-up, then one hard bash, like a blow with a stone.
A game controller now gives a short bump, 75 milliseconds, when you kill a zombie, softer for the MG80, and one bump for a grenade however many it kills. The closer the zombie was, the heavier and longer the bump, up to a hard double thump when you kill one right in your face. A headshot has its own, firmer vibration.
A game controller now gives a firm vibration, a quarter of a second, when you land a headshot, and the closer the zombie was, the stronger and longer it is, up to a full-strength thump with a tail when you shoot one in the face.
Games are free. Starting a game and playing again no longer cost a coin, so there is no waiting for coins to charge, and the coins row is gone from the main menu.
The main menu has a new row, after Store, that says "Vibration, currently on" or "off", and Enter on it switches the controller's vibration. The game remembers it, in settings.json as VIBRATION.
A game controller now vibrates when a zombie hits you, each zombie in its own way: a light punch from the first, scratching pulses from the second and fourth, a heavy mauling from the third, fifth and seventh, a pounce from the sixth, a firm grip when you fail to shake off the animal zombie, a hard smash from the ninth, and a chainsaw that revs up, saws and revs down from the tenth. Shooting the girl who heals you gives a long rumble, and dying gives two hard seconds. Pausing or leaving a game stops it.
A sound and a short vibration tell you when a game controller is found, and another sound when it is disconnected, which also pauses the game. Nothing plays when no controller is found.
A game controller can now play the game. The left stick aims like a swipe: up is 12 o'clock, left 9, right 3, the diagonals 10:30 and 1:30, and down reloads. One lean is one shot, and the MG80 keeps firing while the stick is held. The D-pad works like the arrow keys: left, up and right fire at 9, 12 and 3, left and up together at 10:30, right and up together at 1:30, and down reloads. X reloads, the bumpers change weapon, A shakes off a zombie, and B or Start pauses and resumes.
A game controller now works on the menus and the shop: the D-pad or left stick moves, A selects and B goes back. It uses the same standard layout on Windows, Linux and macOS.
The MG80 now keeps firing while you hold its lane key, like a machine gun. Every other weapon still fires once per press.
The MG80 can now fire again after 0.085 seconds instead of 0.4, and its shots overlap instead of cutting each other off.
The game is now called Sixth Sense Reborn: the window and the main menu say so, the game is SixthSenseReborn.exe, and its download is SixthSenseReborn-Win-<version>.zip.
Sixth Sense Reborn keeps its own save, in a SixthSenseReborn folder, so it never changes your Sixth Sense save. The first time it starts, it copies your Sixth Sense progress, settings and keys.
Added macOS support with a copyable app and VoiceOver or native speech; targets macOS 11 or newer.
